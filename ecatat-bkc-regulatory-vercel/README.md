# e-Catat BKC – Regulatory Based Mockup

Mockup Next.js untuk Aplikasi Pencatatan Online BKC.

## Deploy ke Vercel
1. Upload seluruh isi folder ini ke repository GitHub.
2. Import repository tersebut di Vercel.
3. Framework Preset: Next.js.
4. Root Directory: `./` bila package.json berada di root repository.
5. Build Command: biarkan default (`next build`).
6. Output Directory: KOSONGKAN / jangan isi `public`.
7. Deploy.

## Catatan
- CSCK-1, CSCK-3, dan CSCK-9 disusun mengikuti elemen format PMK 94/PMK.04/2018 yang digunakan sebagai dasar mockup.
- CSCK-8 dibuat sebagai menu pencatatan pita cukai rusak berdasarkan konteks kajian; elemen final perlu dikunci pada format ketentuan CSCK-8 yang digunakan.
- Ini mockup front-end, belum menggunakan database/backend.
